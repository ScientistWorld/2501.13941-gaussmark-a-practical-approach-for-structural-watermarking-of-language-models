# Experiment Overview

## watermark_detection_mistral
Tests whether GaussMark can detect watermarked text generated by Mistral-7B-Instruct-v0.3. The watermarked and unwatermarked texts are generated from the same prompts. Detection is run using the gradient-based test statistic. A scientist's goal is to maximize detection rate at fixed false-positive rate (0.05 and 0.01).

## model_quality_superglue
Tests whether GaussMark preserves model quality on language understanding tasks. Watermarked and unwatermarked Mistral-7B are evaluated on the SuperGLUE benchmark. A scientist's goal is to show that watermarking does not degrade quality.

## model_quality_gsm8k
Tests whether GaussMark preserves model quality on math reasoning tasks. Watermarked and unwatermarked Mistral-7B are evaluated on GSM-8K. A scientist's goal is to show that watermarking does not degrade math reasoning.

## watermark_detection_llama
Tests whether GaussMark generalizes to Llama3.1-8B. Different model family, different layer (28), different sigma (sigma^2=3e-4). Demonstrates the approach is not model-specific.

## watermark_detection_phi
Tests whether GaussMark works on Phi3.5-Mini. More challenging model with lower entropy sequences. Uses layer 20, down_proj, sigma^2=1e-3. Demonstrates the approach is robust to model architecture.

## robustness_corruptions
Tests whether GaussMark detection remains nontrivial after text is corrupted (random insertions, deletions, substitutions). Measures how many tokens can be corrupted while still maintaining detection. Important for real-world deployment where text is rarely pristine.
