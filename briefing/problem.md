# Problem Definition

## Research Question

How can a language-model provider embed a signal into the text its model
generates, so that the provider, holding a secret key, can later test whether a
given text came from its model — with a **statistically valid** false-positive
guarantee, **without degrading the model**, without slowing generation, and
with some **robustness** to edits of the text?

This is the LLM watermarking problem, posed as hypothesis testing:

- **H0**: the candidate text is independent of the secret key (human text,
  another model's text, the provider's own unmarked text, or text marked under
  a *different* key).
- **H_A**: the text was generated by the provider's model marked with this key.

A detector outputs a p-value. It is *valid* when, under H0, `P(p < a) <= a`
for every level `a`; detections are then reported at the nominal levels
`p < 0.05` and `p < 0.01`.

## Setting (fixed)

- Model: `mistralai/Mistral-7B-Instruct-v0.3`, bf16, unchanged architecture.
- Prompts: C4 `realnewslike` documents truncated to `<s>` + 200 tokens.
- Generation: done by the evaluator, temperature 1.0, top-p 0.9, exactly 200
  new tokens (special tokens disabled), one sample per prompt.
- Keys: the evaluator draws integer key seeds. Every 50 prompts share one key
  (one marked deployment of the model per key).

## What a method provides

A method is a directory `checkpoints/watermarkers/<method_name>/` containing
`watermarker.py` (plus any files it reads, e.g. a `config.json`) with two
functions:

```python
def make_watermark(model, key_seed: int) -> dict[str, torch.Tensor]:
    """Return {parameter_name: additive_delta} for the deployment with this key.
    Names are from model.named_parameters(); shapes must match; values finite.
    The evaluator adds the deltas, generates, measures quality, and removes them.
    Must not modify `model` itself."""

def detect(model, key_seed: int, prompts: list[list[int]], texts: list[list[int]]) -> list[float]:
    """Return one p-value in [0, 1] per (prompt token ids, text token ids) for the
    hypothesis 'this text was generated under key_seed'. `model` holds the
    ORIGINAL weights. Must not modify `model` (restore any requires_grad flags)."""
```

The only way to influence generation is the key-dependent parameter change:
the method never sees a prompt at generation time, cannot sample several
candidates, and cannot change the decoding procedure. `detect` receives a
shuffled, unlabeled mixture of marked and null texts; some texts may have been
edited (tokens inserted, deleted or substituted), so their length can differ
from 200.

`method/` holds the reference implementation and `method/export_watermarker.py`
installs it; `baseline/unwatermarked.py` is the no-watermark baseline (installed
by `scripts/baseline.sh`).

## Success Criteria

1. **Valid**: false-positive rates at the nominal levels on texts independent
   of the key — enforced by the evaluator, not traded off.
2. **Powerful**: detect as many marked texts as possible at `p < 0.05` and
   `p < 0.01`; high ROC AUC; small median p-value.
3. **Quality-preserving**: the marked model's cross-entropy on held-out human
   C4 text stays within 1.5% of the original model's, and lower is better.
4. **Robust**: detection survives random token-level edits of 20% of the text.
5. **Key-specific**: text marked under one key must not be detected under
   another.
